# **App Name**: PersonaFlow

## Core Features:

- Page Routing: Enable navigation between Home, About, Projects, Skills, and Contact pages.
- Hero Section: Display name, profession, and a 'Download CV' button.
- About Section: Include a short introduction, profile photo, and key highlights.
- Projects Display: Showcase 4-6 projects with title, image, description, GitHub link, and live demo link.
- Skills Showcase: Present skills in a grid layout with skill cards.
- Contact Form: Implement a contact form (name, email, message) with client-side validation and console logging.
- Animated Transitions: Add smooth page transitions and animations using Framer Motion.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to evoke creativity and calmness.
- Background color: Very light desaturated lavender (#F5F5FF), nearly white, for a clean backdrop.
- Accent color: Pale violet (#D8BFD8), for highlighting interactive elements.
- Font pairing: 'Belleza' for headlines (sans-serif) and 'Alegreya' for body text (serif).
- Use modern, minimalist icons for social media and navigation.
- Implement a responsive design using Tailwind CSS grid and flexbox for optimal viewing on various devices.
- Incorporate subtle fade-in and slide-up animations using Framer Motion for a smooth user experience.
